# Global Superstore — Sales & Business Intelligence Dashboard

An interactive six-page Power BI dashboard analyzing sales performance, profitability, customers, products, regional operations, shipping, and returns.

## Dashboard Preview

![Executive Overview](screenshots/01-executive-overview.png)

## Project Overview

This project uses Power BI to transform retail order data into an interactive business intelligence report. It demonstrates data preparation, data modeling, DAX measure development, and dashboard design.

## Dashboard Pages

### 1. Executive Overview

Summarizes sales, profit, orders, customers, profit margin, category performance, regional performance, and returns.

### 2. Sales Performance

Analyzes sales trends, market performance, customer segments, product rankings, year-to-date sales, year-over-year growth, and cumulative sales.

### 3. Profitability Analysis

Examines profit trends, margins, discount relationships, category profitability, and sub-category performance.

### 4. Customer & Product Analysis

Explores customer contribution, product performance, category sales, and customer profitability.

### 5. Regional & Operations Analysis

Analyzes regional sales and profit, shipping costs, delivery time, shipping modes, and order priority.

### 6. Returns & Business Insights

Examines returned orders, return rates, returned sales, and return patterns across markets, categories, and segments.

## Data Preparation & Modeling

* Cleaned and prepared source data using Power Query.
* Applied appropriate data types and text-cleaning steps.
* Created a dedicated date table for time intelligence.
* Established relationships between orders, dates, regional lookup data, and returns.
* Developed measures for sales, profit, orders, customers, and operational KPIs.

## Advanced DAX Features

* Year-to-date calculations
* Previous-year comparisons
* Year-over-year growth
* Running totals
* Percentage of total
* RANKX-based ranking
* Dynamic Top N analysis
* Dynamic metric selection
* TREATAS-based returned-order analysis
* Return-rate and profitability metrics

## How to Use

1. Open the `PowerBI` folder.
2. Download `Global_Superstore_Professional_Dashboard.pbix`.
3. Open it in Microsoft Power BI Desktop.
4. Use the slicers and visuals to explore the report.
